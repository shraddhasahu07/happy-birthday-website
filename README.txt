YOUR BIRTHDAY FRIENDSHIP WEBSITE

WHAT IS INCLUDED
- index.html: complete mobile-friendly website
- YES/NO welcome screen (NO button moves away)
- Six story slides with your supplied text
- Separate music player for each slide; changing slides stops the previous song

ADD YOUR MUSIC
Put your own MP3 audio files in the SAME folder as index.html and use these exact filenames:
1. love-you-zindagi.mp3 (Welcome page)
2. jaane-kyun.mp3
3. girls-like-to-swing.mp3
4. count-on-me.mp3
5. gallan-goodiyaan.mp3
6. tenu-sang-rakhna.mp3
7. atrangi-yaari.mp3

The site works without MP3 files, but the music buttons will not have audio to play. Browsers require a button tap before music can start. Use audio files you are allowed to use. The website does not download songs.

PUBLISH FREE WITH GITHUB PAGES
1. Open this repository: https://github.com/shraddhasahu07/happy-birthday-website
2. Go to repository Settings > Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait for the website link to appear in Settings > Pages.

GitHub Pages is free for eligible public repositories, subject to GitHub's terms and usage limits.
